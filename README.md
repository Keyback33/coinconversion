# 💱 CoinConversion

Aplicación personal Flutter para consultar y convertir monedas fiat en Android. El código fuente usa dólar MEP venta como referencia para ARS, además de una tabla general para las otras monedas. Conserva ambos datos por separado para uso offline.

## 📲 Descargar

- [APK firmado 1.0.2](dist/coinconversion-1.0.2.apk)
- [Checksum SHA-256](dist/coinconversion-1.0.2.apk.sha256)

Requiere Android 7.0 / API 24 o posterior. La release incluye Frankfurter como fallback general sin credenciales, MEP para cruces con ARS y las secciones colapsables.
