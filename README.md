# 💱 CoinConversion

Aplicación personal Flutter para consultar y convertir monedas fiat en Android. Descarga cotizaciones, calcula conversiones localmente y conserva el último snapshot para continuar funcionando offline.

## 📲 Descargar

- [APK firmado 1.0.1](dist/coinconversion-1.0.1.apk)
- [Checksum SHA-256](dist/coinconversion-1.0.1.apk.sha256)

Requiere Android 7.0 / API 24 o posterior. La release publicada utiliza el provider principal y cache; no incluye un `OXR_APP_ID` personal para el fallback autenticado.
